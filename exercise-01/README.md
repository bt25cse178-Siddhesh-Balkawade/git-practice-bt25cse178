# Exercise 01 – Configure Git

## Objective

To check the installed Git version, configure the repository-local username and email address, and verify the configured details.

## Commands Used

```zsh
git --version

git config user.name "Agraj Shukla"
git config user.email "agrajshukla.is.here@gmail.com"

git config --get user.name
git config --get user.email
```
